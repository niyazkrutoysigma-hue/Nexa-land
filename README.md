# ◆ NEXA LAND

Лаунчер Minecraft: Java Edition для Windows. Тёмно-фиолетовая тема, сборки (Fabric / Quilt / Forge / NeoForge), мощное меню дополнений (Modrinth + CurseForge, 1000+ модов по категориям), аккаунты Microsoft.

Написан на C# / .NET 10 (WPF), **без внешних NuGet-пакетов** — только BCL и системные API.

---

## Что внутри

### 🏠 Главная
Быстрый запуск последней сборки, кнопки «Моды сборки» / «Каталог версий» / «Новая сборка», живая статистика (число сборок, модов, состояние аккаунта, версия Java, размер общего стора) и список недавних сборок с действиями «Играть» и «Моды».

### 📦 Сборки
Своя папка у каждой сборки (миры, моды, конфиги, скриншоты, логи), изолированные или общие библиотеки. На карточке:

| Кнопка | Действие |
|---|---|
| **Играть** | докачать файлы, поднять Java и запустить игру |
| **+** | **меню дополнений** — моды этой сборки (Modrinth / CurseForge) |
| **⋯** | папки (игра, моды, миры, конфиги, логи), дублирование, экспорт модпака, удаление |

### 🧩 Меню дополнений (окно «NEXA LAND — Моды сборки»)
- **Вкладка «Установленные»** — открывается по умолчанию: список модов с версией, размером, источником, вкл/выкл и удалением.
- **Вкладка «Modrinth»** и **«CurseForge»** — каталоги с обложками.
- **Категории-чипы**: Все, Оптимизация, **Хоррор**, Декорации, Технологии, Геймплей, Приключения, Библиотеки, Бой, Передвижение, Генерация миров, Интерфейс, Социальные, Разное. По умолчанию выбрано **«Все»**.
- **Сетка карточек** с пагинацией: 100 модов за раз, «Найдено 11 774 модов · Загружено 100», кнопка «Загрузить ещё 100 модов» и автоподгрузка при прокрутке.
- Сортировка: популярные / новые / обновлённые / избранные.
- Поиск с Enter — фильтрует каталог.
- Установка **с автоматической установкой зависимостей** (Sodium подтянет за собой cloth-config и т.п.).
- Кнопка «Обновить всё» — ищет новые версии установленных модов и предлагает обновить.
- **Импорт/экспорт `.mrpack`** (модпаки Modrinth).
- CurseForge требует API-ключ (вкладка подскажет, где его взять, если ключа нет).

### ⬇ Каталог версий
Все релизы и снапшоты Mojang, установка в один клик, мастер сборки с выбором загрузчика, памяти и аргументов.

### 👤 Аккаунты
Вход по коду Microsoft (device code, без встроенного окна входа) и оффлайн-профили. Токены шифруются **DPAPI** и привязаны к вашей учётной записи Windows.

### 🎨 Настройки
Память (по памяти системы), авто-подбор и авто-скачивание Java (Temurin), пути, тёмная/светлая тема, 9 акцентных цветов, автообновление лаунчера через GitHub Releases, очистка кэша.

### 🧾 Консоль
Логи лаунчера и игры в реальном времени: фильтры, автопрокрутка, копирование.

### Прочее
- Всплывающие тосты с действиями (в правом верхнем углу).
- Горячие клавиши: **F5** — обновления, **F6** — обновить списки.
- Иконка приложения и логотип — сгенерированный ромбик в фиолетовой гамме (файл `logo.png` в папке данных).

## Требования

- Windows 10/11 x64
- .NET 10 Desktop Runtime (для запуска) / .NET SDK 10 (для сборки)
- Java ставится сама: если нужной версии нет, лаунчер скачивает Eclipse Temurin JRE

## Сборка и запуск

```powershell
dotnet build src/MinecraftLauncher/MinecraftLauncher.csproj -c Release
dotnet run   --project src/MinecraftLauncher/MinecraftLauncher.csproj
```

Готовый бинарник: `src\MinecraftLauncher\bin\Release\net10.0-windows\NexaLand.exe`

### Командные режимы

```powershell
# самопроверка: сеть, version.json, слияние Fabric, аргументы запуска, Modrinth, установка мода
NexaLand.exe --selftest [версия]

# скачать версию заранее
NexaLand.exe --install 1.21.1

# скачать и сразу запустить
NexaLand.exe --launch 1.21.1
```

`--selftest` выполняет 12 проверок, включая реальную установку мода с зависимостями во временную папку.

## Где лежат данные

```
%AppData%\NexaLand\
├── settings.json      настройки
├── instances.json     список сборок
├── accounts.dat       аккаунты (шифрование DPAPI)
├── logo.png           иконка приложения
├── instances\<id>\    папка сборки: mc\ (миры, моды, конфиги, логи) + versions\ + libraries\ + mods\.nexa\
├── shared\            общий стор: assets\, versions\, libraries\
├── java\              скачанные лаунчером JRE
├── cache\             кэш загрузок и обложек
└── logs\              логи
```

При первом запуске данные из старой папки `%AppData%\MinecraftLauncher` переносятся автоматически (скачанные версии не теряются).

## Заметки по реализации

- **Наследование версий**: библиотеки родителя и ребёнка объединяются (так требуют профили Fabric/Quilt), аргументы дополняются. Слияние — на уровне JSON-дерева, без потери полей.
- **Библиотеки ≤ 1.16.5 (Java 8)**: Mojang описывает каждую LWJGL-библиотеку двумя элементами массива — обычный jar и natives-классификатор — с **одинаковым** `downloads.artifact.path`. Ключ дедупликации обязан различать их по наличию блока `natives`, иначе natives-запись затирает обычную, jar не скачивается и игра падает с `NoClassDefFoundError: org/lwjgl/glfw/GLFW`.
- **Natives в 1.21+**: у современных версий нет блока `natives` — нативные библиотеки идут отдельными записями с классификатором в имени (`org.lwjgl:lwjgl-glfw:3.3.3:natives-windows`) и попадают прямо в classpath; распаковка в папку `natives` не нужна.
- **Подбор Java**: для версий до 1.16.5 нужна ровно Java 8 — на 17/21 они не стартуют, поэтому «ближайшая» версия не подходит, лаунчер сам скачивает Temurin 8. Для современных версий берётся минимальная ≥ нужной. Java из настроек используется, только если её версия совпадает с требуемой; встроенные в IDE (Android Studio, IntelliJ, VS Code) runtime — последний выбор.
- **Ассеты**: URL требует двухсимвольный префикс хеша (`/ab/abcdef…`); для версий ≤ 1.5 — плоский формат.
- **`${natives_directory}`** всегда указывает на существующую папку: при пустом значении JNA падает с `temporary directory '' does not exist`.
- **Класс-пас**: библиотеки по правилам ОС, natives вне classpath, клиентский jar последним; у сборок с загрузчиком jar лежит в папке ванильной версии. Перед стартом список сверяется с файлами на диске: если чего-то не хватает, лаунчер докачивает и сообщает об ошибке вместо падения JVM.
- **Сборки без version.json**: ссылка восстанавливается из манифеста Mojang по версии, поэтому сборка, созданная вручную или потерявшая ссылку, всё равно запускается.
- **Защита instances.json**: список сборок не перезаписывается, если в памяти он внезапно пуст, а в файле есть записи.
- **Оффлайн-аккаунты**: UUID считается как `OfflinePlayer:<name>` (как в vanilla), токен `0` — игра в офлайн-режиме.
- **Моды**: для каждого установленного мода пишется маркер `.nexa\<файл>.json` — по нему работают определение «уже установлен», обновления и экспорт модпака.
- **Прогресс установки** агрегированный по сумме байт, скачивание параллельное (6–8 потоков), докачка через Range-запросы.
- **Adoptium**: используется актуальная форма API v3 (`/assets/latest/{major}/hotspot?…`); старый путь `/ga/windows/x64/…` отдаёт 404, в том числе для Java 8.

## Ограничения

- Только Windows x64 и Minecraft: Java Edition.
- CurseForge-каталог требует API-ключа (без ключа вкладка подсказывает, что делать).
- Автообновление лаунчера работает через GitHub Releases: укажите репозиторий в настройках.
- Иконки сборок генерируются программно (WPF-рендер).
